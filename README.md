# تطبيق المحادثة مع الذكاء الاصطناعي المحلي 🤖

تطبيق محادثة تفاعلي يعمل مع نموذج ذكاء اصطناعي محلي (Phi-3.5 Mini) يعمل بالكامل في المتصفح بدون الحاجة لسيرفر خارجي.

## المميزات ✨

- 🔒 **خصوصية كاملة**: النموذج يعمل محلياً في متصفحك - لا يتم إرسال أي بيانات للخارج
- 💬 **محادثات متعددة**: إنشاء وإدارة محادثات متعددة
- 💾 **حفظ تلقائي**: جميع المحادثات تُحفظ في قاعدة البيانات
- ⚡ **سريع وخفيف**: يستخدم نموذج Phi-3.5 Mini المُحسّن
- 🎨 **واجهة عصرية**: تصميم نظيف وسهل الاستخدام مع دعم اللغة العربية

## التقنيات المستخدمة 🛠️

### Backend:
- FastAPI (Python)
- MongoDB (قاعدة البيانات)
- Motor (MongoDB async driver)

### Frontend:
- React 19
- WebLLM (@mlc-ai/web-llm) - لتشغيل النموذج في المتصفح
- Tailwind CSS + Shadcn UI
- Axios

### نموذج الذكاء الاصطناعي:
- **Phi-3.5 Mini** (quantized q4f16_1)
- يعمل بالكامل في المتصفح
- حجم صغير وأداء ممتاز

## كيفية الاستخدام 📖

1. **افتح التطبيق** في المتصفح
2. **انتظر تحميل النموذج** (قد يستغرق بضع دقائق في المرة الأولى)
3. **أنشئ محادثة جديدة** من الشريط الجانبي
4. **ابدأ المحادثة** مع الذكاء الاصطناعي المحلي

## API Endpoints 🔌

### Conversations
- `POST /api/conversations` - إنشاء محادثة جديدة
- `GET /api/conversations` - الحصول على جميع المحادثات
- `GET /api/conversations/{id}` - الحصول على محادثة محددة
- `PUT /api/conversations/{id}` - تحديث محادثة
- `DELETE /api/conversations/{id}` - حذف محادثة

### Messages
- `POST /api/conversations/{id}/messages` - إضافة رسالة جديدة

## ملاحظات مهمة ⚠️

1. **التحميل الأول**: قد يستغرق تحميل النموذج بضع دقائق في المرة الأولى (حوالي 2-3 جيجابايت)
2. **المتطلبات**: يحتاج المتصفح إلى دعم WebGPU (Chrome/Edge الحديثة)
3. **الذاكرة**: يُفضل أن يكون لديك 8 جيجابايت رام على الأقل
4. **الخصوصية**: جميع الحسابات تتم محلياً - لا يتم إرسال بياناتك لأي مكان
